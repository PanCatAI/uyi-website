1. 条款范围与运营主体

本使用条款适用于 UYI 官方网站、邀请制 macOS 应用、UYI Studio 及其配套服务（以下统称“本服务”）。

本服务的实际运营方为哈尔尼斯（北京）科技有限公司广州分公司，属于 Harness Technology (Beijing) Co., Ltd.（哈尔尼斯（北京）科技有限公司）的广州分公司，以下称“我们”。本条款下有关运营、用户合同及服务提供的责任，由实际运营方依法承担。个人信息处理方式请参阅另行公布的《隐私政策》。

2. 同意、使用条件与账号

注册或其他流程要求接受本条款时，请先阅读再同意。接受本条款或确认阅读隐私政策，不等于对所有个人信息使用或跨境传输作出概括同意。需要单独同意的处理活动，仍须依法处理。

邀请资格及具体功能以申请或使用时展示的条件为准。依法需要监护人或其他法定代理人同意的，请取得相应同意。本条款不限制未成年人依法享有的撤销权等权利。代表组织使用本服务时，须具有相应授权。

请准确填写注册信息，妥善管理登录凭据及 API 密钥，不得擅自使用他人的账号或密钥。用户的账号安全义务不免除我们依法应承担的责任。

3. 功能与概念展示

UYI 提供与 AI 角色对话、语音互动、虚拟空间活动及创作辅助。可用功能取决于应用版本、设备环境、设置和使用条件。官网概念视频及原型画面不承诺其中展示的全部功能均已上线。部分 UYI 托管的 3D 资产与动作生成功能仍在研发中。

使用在线模型对话或开展角色自主活动时，会与我们或相应功能配置的外部服务通信。自主活动可能在用户没有发送新消息时处理当前目标、房间状态等内容。选择本地语音或动作模型，不会使其他功能自动变为离线运行。

4. AI 的性质与使用注意

AI 角色不是真实的人，其发言和情绪表达由系统生成。回复、记忆及生成结果可能存在错误、矛盾或不当内容，也可能与其他用户获得的结果相似。请核实重要事实，以及准备采信或公开发布的内容。

本服务不提供医疗、法律、投资等专业意见或紧急救援。上述性质说明不限制我们因故意、重大过失应承担的责任，或其他依法不得免除的责任。

5. 语音、文件与记忆

语音功能需要麦克风权限。按住说话模式在按住操作期间录音；连续语音模式会跨多个对话轮次使用麦克风，直至退出该模式。你也可以在设备设置中撤销麦克风权限。在线语音识别、合成等服务会收到处理所需的音频、待朗读文本等内容。

文件导入会处理你选择的文件或文件夹。房间相机拍摄的虚拟空间不同于电脑桌面画面。音频、图像或文件包含他人的个人信息、秘密或受保护作品时，请确认提供权限与必要性；这不将我们自身的法定义务转由用户承担。

聊天记录与角色记忆保存在设备上，目前我们不为这两类数据提供云备份。但在线模型仍会收到处理请求所需的内容，包括可能涉及的对话上下文和相关记忆。聊天与记忆分别保存，因此删除聊天后，由其形成的记忆可能仍然存在。个人信息的接收方、用途及保存、删除方式请参阅隐私政策。

6. 使用额度、外部费用与邮箱报名

使用额度、余量及相关条件请查看账号或功能界面。仅接受本条款不会产生收费、自动续费订阅或额外购买。若提供付费服务，我们会在购买前展示价格、计费方式以及续费、取消和退款条件。用户依法享有的退款等权利不受限制。

自行配置 API 密钥或外部服务账号（BYOK）时，适用该提供者的条款、费用与使用限制。向外部提供者支付费用以你与其订立的协议为准。模型和连接目标可能按功能分别设置，某项功能的配置不一定适用于其他功能。

官网邮箱报名为自愿行为，不保证获得使用资格或特定时间的邀请。可使用报名邮箱联系 partnerships@uyi.live，申请删除报名资料或退订。报名邮箱保留 12 个月。

7. 输入素材与生成结果的权利

你对消息、音频、图像和文件等输入素材享有的权利仍归你所有。对于生成结果，法律基于你的创造性贡献等认可的权利，也不会因本条款转移给我们。但 AI 生成内容不保证必然受著作权保护、具有独占性或不涉及第三方权利。

对于发送给我们的输入，你授予我们非独占、免费的许可，仅在提供你请求或启用的功能所需范围内接收、中转、转换格式、分析并生成结果。受我们委托的提供者可为相同目的进行必要处理。仅保存在设备上或导出为本地文件的内容，不视为提交给我们。

上述许可不包含我们公开私密输入或作品、用于宣传或用于模型训练的权利；此类用途应另行取得必要许可和同意。这说明的是本条款授予的许可范围，不是对外部提供者实际保存、训练行为的统一保证。个人信息处理所需的说明与同意也应单独满足。

UYI 或第三方提供的角色、模型、动作、图像、音乐、软件等素材，其权利归各权利人所有。将其用于作品不使相关权利自动转移。公开发布、直播、再分发或商业使用前，请核对各项素材的许可。单个素材适用的开放许可不自动适用于整个产品或其他素材。

兼容 API 或用户自定义接口，不一定属于其名称涉及品牌的官方服务。请确认实际连接目标及其条款与隐私说明。外部服务的条款不当然免除我们自身的责任。

目前房间日记在设备上的虚拟空间中阅读，场景导出生成本地文件；这些操作本身不会将作品公开到互联网。另行传送文件或发布到外部平台前，请检查分享内容、素材权利及目标平台条件。若提供由我们在线公开用户作品的功能，将另行说明公开范围、许可及删除条件。

10. 停止使用、删除与保存

你可以随时停止使用本服务。退出登录会结束当前登录会话；注销账号会停用账号并撤销登录，但保留注销标记和后台操作记录。退出登录、注销账号或卸载应用，不等于完整清除所有本地数据或服务器记录。

主动提交的诊断报告及附件保留 30 天，登录后可以提前撤回。撤回会清除描述和关联请求标识，并删除附件；已生成的临时下载链接可能在到期前仍可使用。

请根据需要管理设备上的聊天、记忆等数据及其备份、删除。没有云备份的数据可能因设备遗失或故障丢失。保存与删除的具体说明以隐私政策为准。这些说明不限制我们的法定义务或用户权利。
